Purchase Orders

Read-only viewer for SAP S/4HANA Cloud API_PURCHASEORDER_2 (OData V4). Nothing is written back to the service.

Connection

The key is held in memory for this tab only. It is never written to the URL, local storage, session storage, logs or this page’s source, and it is cleared when you press Clear connection. Retrieval needs an internet connection.

Filters

Filters are sent to the service as an OData $filter expression. The date range is inclusive; both ends are optional.

Page 1

Total value is computed by this page as the sum of the line items’ net amounts (NetAmount) for that purchase order. The API has no header total field, and unit prices are never summed. A value stays Pending until the complete item list is available, shows Unavailable when an item amount or currency is missing, is non-numeric, or when items use mixed currencies, and shows Partial when the item list is incomplete. A missing item currency is never assumed from the purchase order.

Status code is the raw PurchasingProcessingStatus value returned by the service. The API metadata contains no code-to-label mapping, so codes are shown untranslated rather than guessed.

Pages are fetched with $top/$skip; a page is never the whole dataset. Where the service does not report a row count, the page count is unknown and only page navigation is shown.
